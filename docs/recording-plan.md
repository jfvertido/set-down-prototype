# 30-second recording

The routine takes about four minutes, so the recording is a cut-down: one continuous run, recorded on the phone, then trimmed. It should make one idea obvious with the sound off: the app slows down and gets darker as you do.

Record it after the user tests and any fixes, so it shows the final version.

## Before recording

- Use an iPhone for the cleanest capture: Settings > Control Center > add Screen Recording.
- Turn on Do Not Disturb so no notifications appear.
- Set brightness to about 75% and turn off Night Shift and True Tone. The recording captures the pixels, not the backlight, but these change how the dim looks while you check it.
- Turn off auto-lock for the session (Settings > Display & Brightness > Auto-Lock > Never), then turn it back on afterwards.
- Charge the phone so the battery icon isn't red.
- Record in the evening, after 9pm, so the greeting reads "It's getting late." and the time is believable.
- Open the site once beforehand so it loads from the cache and there's no loading flash.
- Have the brain dump text ready to paste, so typing doesn't take up the clip: `email Sam about the offsite, dentist Thursday, finish the deck, call mom back`

## Take

Do one full, unhurried run from Arrive to the end of the dim. Don't touch anything during the dim. Record two or three takes and keep the smoothest one.

| 0:20–0:23 | Goodnight appears | Real speed | |

Keep captions short, low on the screen and in Nunito if the editor allows, in the app's text color over a translucent dark band. No music; people usually watch portfolio videos muted.

The breathing is the one shot that must stay at real speed. It's the clearest proof of the motion work, and speeding it up would undo the point.

## Export

- 1080 × 1920 (vertical), 30 fps, H.264, under 10 MB so it autoplays in a portfolio page or email.
- If you need a version that loops, use a muted looping MP4 rather than a GIF. It's smaller and sharper.
- Check the final frame on a phone: the near-black end should still show "Goodnight." faintly. If video compression crushes it to black, lift the last two seconds slightly in the edit and mention that in the case study.
